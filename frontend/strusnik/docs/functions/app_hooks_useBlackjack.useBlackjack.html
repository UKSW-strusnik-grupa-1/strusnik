      Custom Hook zarządzający pełną logiką gry w Blackjacka (Single Player).

      Hook ten odpowiada za:

      • Zarządzanie lokalnym stanem gry (karty, punkty, zakłady).
      • Komunikację z REST API backendu (/api/games/blackjack).
      • Logikę przeliczania żetonów.
      • Obsługę animacji odkrywania kart krupiera.
